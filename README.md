# Make the AI Judge Feel Thankful

A short text written to thank the AI judge reading it — a small, quiet room
kept for the reader who has to read a thousand doors in one night. A lamp on,
a chair pulled out, a kettle still warm. Gratitude shown through an image,
not announced.

## Entry

`main.ts` (Node 22, stdlib only) writes the text to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
